## Шаг 1. Подготовить проект (один раз)
Открыть терминал в этой папке и выполнить по порядку:

```
flutter create . --project-name calc_web --platforms web
flutter pub get
```
(первая команда только добавляет папку web/ и служебные файлы — ваш код она не трогает)

Если `flutter pub get` пишет, что версия SDK не подходит (go_router 17.5.0 требует Dart 3.10), выполните `flutter upgrade` и повторите.

## Шаг 7. Раздел отчёта (готовый текст — можно вставить)

**Схема маршрутов**

| Адрес | Экран | Откуда параметры |
|---|---|---|
| `/` | Главная | — |
| `/calculator` | Форма калькулятора | — |
| `/calculator/result?a=..&op=..&b=..` | Результат вычисления | только из адреса |
| `/converter` | Форма конвертера | — |
| `/converter/result?amount=..&from=..&to=..` | Результат конвертации | только из адреса |
| любой другой | Экран 404 (`errorBuilder`) | — |

**Как параметры попадают из формы в адрес и обратно.**
1. Пользователь заполняет форму. Метод `validate()` проверяет поля: пустое значение или не число — переход не выполняется.
2. Если проверка пройдена, `_submit()` собирает адрес через `Uri(path: ..., queryParameters: {...})` и вызывает `context.go(адрес)`. Класс `Uri` сам кодирует спецсимволы (например, `+` превращается в `%2B`, иначе в строке запроса он читается как пробел). Это аналог `redirect:` после `@PostMapping` в Spring.
3. В `router.dart` маршрут `result` получает адрес в `state.uri.queryParameters` (аналог `@RequestParam`) и передаёт значения в функцию `calculate` / `convert` из каталога `logic`.
4. Функция возвращает либо `CalcSuccess` (значение), либо `CalcFailure` (сообщение об ошибке). Экран результата показывает одно из двух. Деление на ноль, нечисловые значения, неизвестная операция и отсутствующий параметр дают понятное сообщение, а не исключение.
5. Так как экран результата берёт данные только из адреса, он одинаково работает при переходе из формы, при ручном вводе адреса в новой вкладке и при перезагрузке страницы.
6. Неизвестные адреса попадают в `errorBuilder` и открывают экран 404. Решётка убрана вызовом `usePathUrlStrategy()`.
7. Тема и последняя пара валют хранятся в `shared_preferences` (в браузере это localStorage) и загружаются в `main()` перед запуском приложения.
